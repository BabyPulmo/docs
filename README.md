## Brand

The product was originally **ShishuKantho** (Bangla for "Child's Voice"). After name analysis (see `submission/names.md`), we picked **Baby Pulmo** as the international brand and acquired the `babypulmo.com` domain on 2026-05-24. The GitHub org name `Shishukantho` is preserved for now; trademark filing strategy is in `submission/ip-strategy.md`.
